# AULing

AULing, Ankara Üniversitesi Dilbilim Topluluğu üyeleri tarafından geliştirilmiş web sitesi ve dijital içerik platformudur. Topluluk etkinlikleri, dilbilim yazıları, dergi içerikleri ve üyelere yönelik duyurular bu platform üzerinden paylaşılır.

## Teknoloji

Basit ve hafif bir site olması için HTML, CSS ve az sayıda JS kullanılarak geliştirilmiştir.
